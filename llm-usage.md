## Использование LLM в работе над заданием task4 (convex-polygons)

Ниже кратко приведены вопросы, которые определили ход решения, и полученные на них ответы.

### 1. Есть ли в Python встроенная функция для угла между тремя точками?

**Ответ.** Нет: ни в стандартной библиотеке (`math`, `cmath`, `statistics`), ни в NumPy, SciPy и Shapely такой функции нет. В `math` есть только строительные блоки: `atan2`, `acos`, `hypot`, `dist`, `degrees`. Угол обычно считают вручную через векторы, а для проверки выпуклости сам угол можно и не считать: достаточно знака векторного произведения.

### 2. Можно ли посчитать угол точнее через скалярное произведение? Что такое cross?

**Ответ.** Да. Скалярное произведение точнее, чем теорема косинусов через длины, потому что для целых координат считается точно. Но `acos` плохо обусловлен около 0° и 180°, поэтому лучше формула `atan2(|cross|, dot)`: она устойчива на всём диапазоне, не делит на длины сторон (нет деления на ноль при совпадающих вершинах) и не требует зажима аргумента.

`cross = ux·wy − uy·wx` это z-компонента векторного произведения двух векторов на плоскости, равная `|u|·|w|·sin φ`. Её знак показывает направление поворота (больше нуля означает левый поворот), а модуль равен площади параллелограмма на этих векторах. Скалярное произведение `dot = |u|·|w|·cos φ`, поэтому общий множитель в `atan2` сокращается, и получается угол. Модуль у `cross` нужен, чтобы угол был неориентированным, из диапазона [0°, 180°].

### 3. Что такое триангуляция? Можно ли провести диагонали из первой вершины?

**Ответ.** Триангуляция это разбиение многоугольника на непересекающиеся треугольники с вершинами в вершинах самого многоугольника. У многоугольника с `n` вершинами всегда получается `n − 2` треугольника и `n − 3` диагонали. Для выпуклого многоугольника достаточно провести диагонали из первой вершины: треугольники `(v0, vi, vi+1)` покрывают его без перекрытий, потому что все диагонали выпуклого многоугольника лежат внутри. Метод `triangulate` возвращает список треугольников, каждый задан тремя вершинами.

### 4. Площадь получилась 15.999999999999995, как получить 16?

**Ответ.** Причина в формуле Герона: она использует корни (`math.dist`, `sqrt`), и ошибки накапливаются. Площадь треугольника лучше считать через векторное произведение: `S = |ux·wy − uy·wx| / 2`. Это половина площади параллелограмма на двух сторонах треугольника. Тут нет корней, поэтому для целых координат результат точный, и площадь шестиугольника получается `16.0`.

### 5. Как найти точки пересечения двух многоугольников?

**Ответ.** Вершины пересечения бывают двух видов: точки пересечения рёбер и вершины одного многоугольника, лежащие внутри другого. Пересечение двух отрезков находится через параметрическое представление `P = A + t·(B − A)` и решение системы 2×2 (правило Крамера); перебор всех пар рёбер стоит O(n·m). Нужно учесть параллельные рёбра, повторяющиеся точки и сравнение float с допуском. Если в итоге меньше трёх различных точек, пересечение пусто или вырождено.

### 6. Можно ли построить пересечение без алгоритма Сазерленда-Ходжмена?

**Ответ.** Да, есть три основных способа: сбор кандидатов в вершины с упорядочиванием по углу, пересечение полуплоскостей и алгоритм О'Рурка за O(n+m). Выбран первый: собираются вершины одного многоугольника внутри другого и точки пересечения рёбер, дубликаты удаляются, остальные точки сортируются по полярному углу вокруг центра. Он опирается на уже написанные части и легко проверяется по отдельности.

### 7. Как проверить, что точка внутри многоугольника? Почему знак cross задаёт «лево/право»?

**Ответ.** Для выпуклого многоугольника при обходе против часовой стрелки точка лежит внутри, если она слева от каждого ребра, то есть `cross(A, B, P) ≥ 0` для всех рёбер.

Знак объясняется так: `cross = |u|·|w|·sin φ`, где φ это угол поворота от ребра `u` к вектору на точку `w` против часовой стрелки. Если повернуть систему координат так, чтобы `u` лежал на оси x (`u = (L, 0)`), то `cross = L·wy`, и знак равен знаку высоты точки над прямой. Поворот системы координат значение `cross` не меняет. То, что положительное направление это против часовой стрелки, принято по соглашению.

### 8. Как найти точку пересечения отрезка с многоугольником? (алгоритм Кируса-Бека)

**Ответ.** Отрезок `AB` записывается как `P(t) = A + t·(B − A)`, `t ∈ [0, 1]`. Для каждого ребра `C→D` величина `f(t) = sA + t·(sB − sA)` линейна по `t`, где `sA` и `sB` это значения `cross` для концов отрезка. Условие `f(t) ≥ 0` отсекает часть отрезка:

- `d = sB − sA > 0`: отрезок входит в полуплоскость, поднимаем нижнюю границу `t_in`;
- `d < 0`: отрезок выходит, опускаем верхнюю границу `t_out`;
- `d = 0`: отрезок параллелен ребру, и если `sA < 0`, он целиком снаружи.

После всех рёбер остаётся `[t_in, t_out]`; если `t_in > t_out`, пересечения нет. Метод `clip_segment` возвращает пару точек `(P_in, P_out)` или `None`.

Пример: для квадрата `(0,0), (4,0), (4,4), (0,4)` и отрезка `(-2,2) → (2,2)` получается `t_in = 0.5`, `t_out = 1`, то есть участок `(0,2) → (2,2)`. Так как `t_in > 0`, точка `(0,2)` лежит на границе; так как `t_out = 1`, конец `(2,2)` лежит внутри многоугольника.

### 9. Функция `clip_by_lines` и двойной вызов в `intersect`

**Ответ.** Решение хорошее: оно убирает дублирование. Граница пересечения состоит из кусков границы одного многоугольника, лежащих внутри другого, поэтому `clip_by_lines` вызывается дважды с поменянными местами многоугольниками, а концы всех полученных отрезков образуют вершины пересечения. Дубликаты неизбежны (одна вершина попадает в несколько отрезков), поэтому они удаляются сравнением с допуском (`same`), после чего точки сортируются по углу. Склеивать отрезки в цепочку не нужно.

### 10. Тесты для площади и периметра, выпуклых и невыпуклых многоугольников, пересечения

**Ответ.** Тесты написаны на `pytest` в трёх отдельных файлах:

- `test_area_perimeter.py`: площадь и периметр на фигурах с вручную посчитанными значениями, независимость от направления обхода и начальной вершины, тесты триангуляции (число треугольников `n − 2`, сумма их площадей равна площади многоугольника);
- `test_convexity.py`: выпуклые многоугольники принимаются и приводятся к обходу против часовой стрелки, невыпуклые и вырожденные (стрелка, L-форма, «бабочка», пентаграмма, дубликаты, коллинеарные точки, меньше трёх вершин) вызывают `ValueError`, плюс проверка `calc_angle`;
- `test_intersect.py`: наложение, вложенность, совпадение, касание по стороне и вершине (результат `None`), симметрия `a ∩ b = b ∩ a`, `includes` и случайный тест с фиксированным `seed`.

Ожидаемые значения считались независимо от кода (по геометрии), чтобы тест проверял правильность, а не согласованность программы с самой собой. Все 169 тестов проходят (`poetry run pytest`).
