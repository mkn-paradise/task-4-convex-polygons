# task-4-convex-polygons

Реализация класса выпуклых многоугольников на плоскости. Необходимо 

1. Проверять выпуклость при инициализации из списка вершин. 

2. Добавить методы вычисления площади и периметра

3. Добавить операции пересечения, проверки на нахождение внутри и триангуляции


## Идея решения

Критерий выпуклости многоугольника, содержащего **n** вершин:

```
Для того, чтобы многоугольник, содержащий n вершин, был выпуклым, необходимо и достаточно, чтобы сумма его углов была равна 180*(n-2).
```

Этот критерий будет использоваться при инициализации.

Если критерий выполняется, то инициализация проходит успешно.

Периметр высчитывается как сумма всех сторон многоугольника.

Площадь высчитывается как сумма площадей всех треугольников, полученных в результате триангуляции.

Триангуляция происходит путем проведения из одной вершиный всех возможных диагоналей.

Операция проверки на нахождение внутри выполняется при помощи операции пересечения: например, если результат пересечения фигур A и B равен фигуре B, то фигура B находится внутри фигуры A.

Операция пересечения использует алгоритм Кируса-Бека.


##  Алгоритм Кируса-Бека

Метод **clip_segment** принимает две точки A и B: начало и конец отрезка. Возвращает сечение отрезком AB: отрезок, полученный в результате пересечения данного отрезка AB исходного многоугольника.

Метод **clip_by_lines** принимает многоугольник **other** и возвращает список отрезков, полученных сечением многоугольником **other**.



## Операции

- Триангуляция. Метод **triangulate** возвращает список из треугольников (треугольник представлен как список трех вершин).

- Пересечение. Метод **intersect** принимает многоугольник **other** и возвращает полученный пересечением новый многоугольник.

- Проверка на нахождение внутри. Метод **includes** принимает многоугольник **other** и возвращает True, если **other** лежит в исходном многоугольнике, иначе False.

---

***Примечание 1***. Для подсчета углов используются векторное (а именно значение z-компоненты результирующего вектора, **calc_z_vect_prod**) и скалярное (**calc_scal_prod**) произведения, так как их значения можно вычислить из координат, которые задаются при создании экземпляра класса. Также векторное произведение используется для установки порядка следования вершин: было решено упорядочить вершины против часовой стрелки (метод **set_order**).

***Примечание 2***. Метод **same** принимает две точки **p** и **q**, возвращает True, если они равны, иначе False. При вызовах функций происходят вычисления над float значениями, поэтому результаты могут содержать погрешность. Функция позволяет сравнивать точки с учетом погрешности: точки равны, если их координаты отличаются менее чем на 10^(-9). Для сравнения чисел также используется соответствующий метод **isclose** из модуля **math**.
